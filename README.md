# MengungkapRahasiaMuatanAtom.github.io
Mengungkap Rahasia Muatan Atom adalah media pembelajaran interaktif berbasis web yang dikombinasikan dengan simulasi PhET, dirancang untuk mata pelajaran Kimia Fase E / Kelas X (Materi: Struktur Atom dan Partikel Penyusunnya) menggunakan model Inquiry-Discovery Learning selama 1 x pertemuan (2 JP).
